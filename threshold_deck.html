The Concept

What is THRESHOLD?

The player returns to a Chinese residential compound they left years ago. Five AI NPCs knew them. There is no plot, no objectives, no tutorial.

The experience runs in 13-minute cycles — chosen deliberately (liminal, unlucky). When the timer expires, the player wakes at the entrance again. The same people are still there. They remember everything from every prior cycle.


NPCs do not regenerate until the player triggers the Return Statement — speaking into the empty courtyard, ending the run and beginning a new one with a procedurally generated social graph.

Core Mechanic
TESTIMONIAL — the player is the only node connecting 5 AI minds. They carry what one NPC says to another — live, in their own words, imperfectly. Each receiving Claude instance responds to the player's specific phrasing unpredictably.
Replayability
Return Statement triggers procedural graph generation via Claude API. Different graph = different people = different hidden truth. Every run is structurally distinct.
No Progression Lock
Facial recognition and gesture layer are ambient — they shape NPC behaviour, not gate it. The compound opens on arrival and never closes.

Architecture

Technology Integration

Anthropic Claude API
Each NPC is a separate DialogueComponent with its own conversation history. System prompts are assembled at runtime from UNPCGraphDataAsset — identity, relationships, withheld truths, memory distortions, tonal register. No hardcoded dialogue.
OpenAI Whisper STT
Player speaks via push-to-talk (V key). WhisperSTTComponent captures PCM via Windows waveIn at 16kHz, encodes WAV, POSTs to Whisper, returns transcript. Transcript becomes the TESTIMONIAL — the player's imperfect relay of what they heard.
ElevenLabs TTS
NPC response text is sent to ElevenLabs /with-timestamps endpoint. Returns Base64 PCM + character-level alignment used by NPCLipSyncComponent. Each graph node carries its own ElevenLabsVoiceID — voice is identity.
Emotion + Vision
ONNX facial expression classifier (~10 FPS) detects player emotion from webcam. Injected into Claude context as ambient annotation. NPC may comment on it. Plutchik 8-emotion PAD state machine drives Metahuman FACS blend shapes.
Social Graph (UNPCGraphDataAsset)
Handcrafted for vertical slice (DA_Graph_ThresholdDefault). Procedurally generated per run in Phase 5. Stores NPC nodes (identity, knowledge, withheld truth, memory distortions) and directed relationship edges. NPCGameMode::BeginPlay() pushes the active graph to all 5 NPCs and resolves each NPC's graph node by name-matching.

Input Layer Detail

The Gesture Layer

Gesture input modifies how testimony is received, not what is said. A pinch before relaying something signals the NPC that information is being withheld. A spread signals openness. The NPC's Claude instance reads this annotation before the spoken message.

Injected as a prefix tag in BuildAnnotatedContent():

[Player gesture: PINCH — withholding]
[Player gesture: SPREAD — open disclosure]
[Player gesture: ROTATE — skepticism]
[Player gesture: SPINDLE — connecting sources]

Pinch → EGestureIntent::Withhold
Player signals they are holding something back. NPC may probe or respect the silence.
Spread → EGestureIntent::Disclose
Player signals open, honest delivery. NPC may lower their guard in response.
Rotate → EGestureIntent::Doubt
Player signals skepticism about what they are relaying. NPC reads the ambivalence.
Spindle → EGestureIntent::Synthesise
Player is visibly connecting multiple sources. NPC may recognise the triangulation.

Critical pitfall — JSON conflict
ClaudeAPISubsystem::BuildRequestBody() appends its own JSON format instruction. A second format in the system prompt causes Claude to use wrong field names → ParseResponse() fails → TTS speaks raw JSON aloud. Solution: no format instruction in BuildSystemPromptFromGraph().
Current State

What's Working Now

Dialogue
All 5 NPCs respond via Claude using graph-assembled system prompts. Conversation history persists per NPC across the session. Responses capped at 1–2 sentences.
Voice I/O
Player speaks via Whisper STT (hold V). Each NPC responds in their own ElevenLabs voice. Lip sync driven by character-level timestamps.
Emotion Engine
Claude returns an emotion hint per response. Full-strength signal drives FACS blend shapes. Slow decay (0.003/s) — emotion holds across the conversation.
Multi-NPC Focus
Player walks freely. Nearest NPC in forward hemisphere becomes active. HUD rebinds dynamically. Only the focused NPC's camera pipeline runs.
Social Graph
Handcrafted graph with 5 nodes + 7 edges loaded at startup. Each NPC's prompt includes their knowledge, withheld truths, memory distortions, and how they view every other NPC by name.
Body + Face
Breathing, head drift, shoulder sway, nods. Thinking pose (brow overlay) while waiting for Claude. Full Metahuman FACS via RigLogic morph targets.
