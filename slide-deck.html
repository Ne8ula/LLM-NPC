⚡ Rate Limiting

Claude: 0.5s minimum interval between requests. 429 / 5xx → exponential backoff (1s → 2s → 4s ±25% jitter), max 3 retries.

🔄 Async Pattern

All HTTP callbacks dispatch to game thread via AsyncTask(ENamedThreads::GameThread) before delegate broadcasts.

[Player Emotion Context] ← from ONNX vision
  Detected: neutral (confidence: 0.82)

[Conversation History]  ← rolling 20-turn buffer
  [user] "...", [assistant] "..."

Parse failures fall back to raw text string extraction. Emotion defaults to Neutral on malformed JSON. item_give: null skips inventory check.

☁ External APIs

3 cloud APIs — highest latency (~100ms–2s). Rate-limited, retried, async. Require internet + API keys.

▣ On-device ONNX

2 ONNX models (face + hand) — run locally via OpenCV DNN. 10 FPS (face) / 15 FPS (hand). No API call.

⚙ Runtime Engine

PAD state machine — pure C++ math, per-frame tick. Integrates Claude emotion deltas with decay (0.05/s).

PAD Emotion State Machine

Pleasure · Arousal · Dominance

Each emotion maps to a canonical point in continuous 3D space. Claude's emotion_update acts as a delta vector. State decays toward neutral at 0.05/s.

Graph-Based Transitions

EmotionGraphDataAsset defines nodes (emotions) and edges (transition rules). Each edge has conditions: minimum PAD distance, time-in-state, signal strength. Evaluated each tick — lowest-cost valid path wins.

Per-NPC Transition Costs

Each NPC archetype defines a cost map for reaching each emotion. A stoic NPC has high cost for Sadness, low for Neutral. A volatile NPC has low cost for Anger. Drives personality without changing the core algorithm.

Inventory & Emotion-Gated Mechanics

How Items Unlock

Each item in InventoryDataAsset has a FEmotionUnlockCondition:

FEmotionUnlockCondition {
  EmotionType:  ETrust,
  MinIntensity: 0.7,    // PAD threshold
  MinDuration:  10.0s,  // must be sustained
  Keywords:     ["key", "tower", "secret"]
}

All three conditions must be met simultaneously. Duration is tracked cumulatively — player must build rapport over the conversation.

Unlock Trigger Chain

Claude → emotion_update raises Trust
↓
PAD state: Trust > 0.7 sustained > 10s
↓
Keyword "key" appears in dialogue
↓
Claude returns item_give: "key_of_the_old_tower"
↓
🎒 NPCInventoryComponent::TryGiveItem() → OnItemGiven

Why This Matters

LLM reasoning directly gates gameplay progression — no scripted branches, no dialogue trees. The NPC decides when to give the item based on emotional read of the conversation.

Fallback Inputs

If Whisper STT fails for 30s → FallbackManagerComponent switches to text input widget. If TTS fails → DialogueFallbackWidget shows text-only response. Zero-downtime degradation.

Summary & Open Challenges

Achievements

  • End-to-end real-time conversational NPC — zero scripted dialogue lines
  • Unified PAD emotional state drives voice, face, and body simultaneously
  • Character-level lip sync from ElevenLabs alignment with asymmetric smoothing
  • Procedural full-body FK animation — no AnimBP assets required
  • On-device ONNX vision keeps player sensing local + private
  • Emotion-gated item unlock — LLM reasoning gates gameplay progression
  • Modular subsystem architecture — new NPC via data asset, no C++ recompile

Open Challenges

  • LLM API latency (~1–2s per turn) breaks real-time immersion at scale
  • ONNX model accuracy degrades under variable lighting / partial occlusion
  • PAD emotional state resets between sessions — no persistence layer yet
  • Voice cloning ethics + ElevenLabs licensing boundaries for shipped games
  • Single NPC only — multi-NPC coordination + shared emotional memory TBD
