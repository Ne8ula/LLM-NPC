Slide 4 · The Animation Problem

UE 5.7 MetaHuman Creator
doesn't expose template switching at runtime.

The MetaHuman Creator preview panel advertises Template Animation swapping (Idle, Happy A/B, Sad A/B, Anger A/B, Fear A/B, Surprise A/B). In practice, this is an editor-time preview system:

  • The Face/Body Template Animation enums live in MetaHumanCharacterEditor — editor-only module.
  • At Assembly time, one template is baked as an AnimSequence. The runtime character plays that single loop and nothing switches it.
  • UMetaHumanComponentUE's runtime API is minimal — it wires one bool (body correctives) and exits.
  • Reflection-based attempts to write a template enum hit a wall: the AnimBPs carry no such property.

Verified via plugin source (MetaHumanComponentUE.cpp, MetaHumanCharacterEditorSettings.cpp) and a runtime component scan.

Slide 5 · The Solution

Play the template clips ourselves —
as crossfading montages.

The plugin ships the actual template clips as standalone UAnimSequence assets under /MetaHumanCharacter/Optional/Animation/TemplateAnimations/. We reach them directly and drive The Friend through the standard animation pipeline.

  • Two minimal slot-host AnimBPs with a single DefaultSlot node: ABP_EmotionSlot_Face, ABP_EmotionSlot_Body.
  • Installed on the Face and Body meshes at init via SetAnimInstanceClass, only when they have no primary AnimInstance (UAF case).
  • Each emotion template plays via PlaySlotAnimationAsDynamicMontage — UE5 auto-crossfades from the outgoing montage to the incoming one on the same slot.
  • ~0.6 s blend-in = blend-out → perceptually smooth A→B transitions between emotional templates on both face and body.

UTemplateAnimationDriverComponent — one component, ~400 LOC, reusable across NPCs; falls back to PlayAnimation hard-swap on non-UAF characters.

Slide 6 · Claude → Template, Direct

What she's feeling right now
drives what she looks like.

By default, template selection listened to UEmotionComponent::OnEmotionChanged. That component runs a PAD state machine with slow decay (~5 min), so a single intense signal holds for a long time — even after Claude had moved on.

Template animation now subscribes to UDialogueComponent::OnDialogueResponseReceived instead. Each Claude turn carries an EEmotionType NPCEmotionHint — we use that directly to pick the next template, and the montage crossfade handles the transition on screen.

  • EmotionComponent stays untouched — still drives voice stability, FACS curves, decay-sensitive systems.
  • Template = Claude's current read. Sadness → SadA/B. Neutral → Idle. Configurable per NPC (Surprise is remapped to Idle for The Friend because her template read too exaggerated).
  • Toggled per-NPC via bDriveFromDialogueResponse on the driver component.
